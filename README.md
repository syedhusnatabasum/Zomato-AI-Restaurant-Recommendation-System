# 🍽️ Zomato AI-Powered Restaurant Recommendation System

## 📌 Project Overview
An AI-powered restaurant recommendation system that suggests restaurants based on user cuisine preferences, budget, customer ratings, and review sentiment.

## ✨ Key Features
- Cuisine-based restaurant recommendations
- TF-IDF vectorization
- Cosine similarity calculation
- Budget-based filtering
- Customer rating analysis
- Sentiment analysis using VADER
- Weighted recommendation scoring
- Interactive Gradio interface
- Analytics dashboard
- CSV report generation

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- VADER Sentiment
- Gradio
- Google Colab

## 🧠 Recommendation Method
The system calculates a final recommendation score using:

**Final Score = 70% Cuisine Similarity + 30% Normalized Rating**

## 📊 Analytics
The project includes customer sentiment analysis, restaurant ratings, cost comparisons, and recommendation results.

## 📁 Project Files
- `Zomato_Recommendation_System.ipynb` – ML implementation
- `Zomato_Restaurant_Analysis.csv` – Restaurant analysis
- `Zomato_Sentiment_Analysis.csv` – Sentiment results
- `Zomato_Final_Recommendations.csv` – Recommendation output
- `Zomato_Analytics_Dashboard.png` – Analytics dashboard
